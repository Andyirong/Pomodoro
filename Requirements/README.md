## 📊 项目概览

**项目名称**：番茄闹钟 App（Pomodoro Timer App）
**当前版本**：0.1.0（基础架构版本）
**开发框架**：Swift + SwiftUI
**数据库**：SQLite
**架构模式**：MVVM

### 🎯 核心功能

- ✅ 倒计时功能（开始/暂停/停止）
- ✅ 6个快速时间预设（15/25/30/45/60/90分钟）
- ✅ Q版可爱风UI设计
- ✅ 环形进度条显示
- ✅ 呼吸动画效果
- ✅ 粉色渐变背景

### 🗄️ 数据库设计

5张核心数据表：
- `timer_history` - 番茄钟历史记录
- `tasks` - 任务管理
- `user_settings` - 用户设置和积分
- `achievements` - 成就系统
- `statistics` - 统计数据

### 🏆 特色系统

- **积分系统**：根据专注时长智能计算积分（5-30分）
- **成就系统**：15个预定义成就，包括连续使用、专注时长等
- **等级系统**：8个等级称号（新手入门→传奇大师）
- **任务管理**：6种分类、3级优先级
