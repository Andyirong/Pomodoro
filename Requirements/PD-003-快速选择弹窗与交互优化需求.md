**文档编号：PD-003**
**版本：1.0**
**创建日期：2025-12-17**
**最后更新：2025-12-17**

## 1. 功能概述

### 1.1 功能名称
快速选择弹窗化与交互优化（Quick Selection Modal & Interaction Enhancement）

### 1.2 功能目标
优化番茄闹钟App的用户体验，将快速选择功能改为弹窗式交互，并优化控制按钮的交互逻辑，提升整体使用流畅度。

### 1.3 用户价值
- 提升界面简洁性：主界面更加清爽，只显示必要信息
- 增强交互体验：弹窗式选择提供更好的沉浸式体验
- 优化操作流程：长按停止避免误操作，时间状态管理更合理
- 视觉反馈增强：进度条显示更直观，动画效果更流畅

## 2. 功能需求

### 2.1 快速选择弹窗化 [FR-011]

#### 2.1.1 弹窗组件设计
- **弹窗类型**：半屏底部弹窗，从底部升起
- **显示内容**：6个预设时间选项 + 自定义时间输入
- **关闭方式**：
  - 点击外部区域关闭
  - 下滑手势关闭
  - 右上角关闭按钮
- **背景效果**：背景模糊，聚焦弹窗内容
- **动画效果**：弹性升起动画，Spring动画响应

#### 2.1.2 主界面简化
- **替换方案**：将原有的3选项卡片替换为单个时间显示按钮
- **按钮内容**：显示当前选择的时间（如"25分钟"）
- **交互方式**：点击按钮触发时间选择弹窗
- **动画效果**：时间切换时平滑过渡，避免闪烁

#### 2.1.3 时间选项扩展
- **新增选项**：
  - 专注45分钟：深粉色主题
  - 专注60分钟：深粉色主题
  - 休息10分钟：浅薄荷绿主题
  - 休息20分钟：浅薄荷绿主题
  - 休息5分钟：薄荷绿主题（原有）
  - 工作时间25分钟：粉色主题（原有）
  - 长休息15分钟：紫色主题（原有）
  - 自定义时间：紫色主题，支持用户输入

#### 2.1.4 自定义时间输入 [FR-012]
- **输入方式**：小时和分钟分开输入
- **快速选择**：提供5/10/15/30/45/60分钟快捷按钮
- **输入验证**：限制小时0-23，分钟0-59
- **确认机制**：需要用户确认才应用时间

### 2.2 控制按钮交互优化

#### 2.2.1 刷新按钮优化
- **功能描述**：清除所有选择，回退到默认25分钟工作时间
- **行为逻辑**：
  - 停止所有倒计时
  - 重置为25分钟
  - 恢复粉色工作主题
  - 重置进度条为满格
- **禁用状态**：计时器运行时禁用，显示灰色

#### 2.2.2 开始/暂停按钮增强
- **状态管理**：
  - 初始状态：播放图标，"准备好开始了吗？"
  - 运行状态：暂停图标，"专注中..."
  - 暂停状态：播放图标，保持当前时间
- **进度显示** [FR-013]：
  - 按钮周围显示圆形进度条
  - 进度条沿按钮边缘（70px直径）
  - 只在计时器运行时显示
  - 与主进度条同步更新
- **动画效果**：图标切换时使用symbolEffect动画

#### 2.2.3 停止按钮长按机制 [FR-014]
- **触发条件**：仅在计时器运行时可用
- **长按逻辑**：
  - 需要持续按压3秒
  - 显示圆形进度条动画
  - 进度条从满格逐渐减少到空
  - 松手时进度条弹性回弹
- **停止行为**：
  - 停止计时器
  - 保持当前选择的时间（不重置）
  - 重置秒数为0
  - 进度条恢复满格

### 2.3 状态管理优化 [FR-015]

#### 2.3.1 禁用状态管理
- **计时器运行时禁用**：
  - 刷新按钮：禁用，显示灰色背景
  - 快速选择按钮：禁用，显示灰色
  - 停止按钮：启用，响应长按

#### 2.3.2 时间状态持久化
- **初始时间记录**：记录用户选择的初始分钟数
- **进度计算**：基于实际选择时间计算进度百分比
- **暂停保持**：暂停后保持当前时间，继续时从暂停处继续

### 2.4 界面设计需求

#### 2.4.1 弹窗布局设计 [NFR-013]
- **布局结构**：
  - 拖拽手柄（顶部）
  - 标题栏："选择时间"
  - 2x3网格布局显示预设选项
  - 自定义时间输入区域
- **尺寸规范**：
  - 弹窗高度：约占屏幕50%
  - 网格间距：水平12pt，垂直12pt
  - 圆角：顶部20pt

#### 2.4.2 视觉风格 [NFR-014]
- **弹窗背景**：白色，顶部圆角，底部阴影
- **选项按钮**：
  - 尺寸：高度100pt
  - 圆角：15pt
  - 阴影：选中时增强
- **进度条样式**：
  - 主进度条：12pt线宽
  - 按钮进度条：4pt线宽
  - 停止进度条：4pt线宽

#### 2.4.3 动画效果 [NFR-015]
- **弹窗动画**：
  - 显示：从底部升起，Spring动画0.5秒
  - 隐藏：向下滑出，Spring动画0.5秒
  - 拖拽：实时跟随手指，松手弹性回弹
- **按钮动画**：
  - 点击：缩放0.95，触觉反馈
  - 选中：Spring动画放大1.03
  - 脉冲：仅非运行状态，2秒周期

## 3. 技术实现

### 3.1 组件架构
```
Demo5/Views/
├── TimePickerModal.swift          # 弹窗主组件
├── QuickSelectButton.swift        # 主界面时间按钮
├── CustomTimeInput.swift          # 自定义时间输入
└── QuickTimePicker.swift          # 原有组件（保留数据模型）

Demo5/Utils/
├── ThemeStyles.swift              # 扩展新TimeType
└── Color+Extensions.swift         # 添加新主题色
```

### 3.2 关键技术点
- **SwiftUI弹窗实现**：使用offset和动画实现自定义弹窗
- **拖拽手势识别**：DragGesture处理下滑关闭
- **状态管理**：@State和@Binding管理复杂状态
- **进度计算优化**：动态基准时间计算
- **动画性能**：使用高效的动画API

### 3.3 代码结构
```swift
// 新增TimeType枚举值
enum TimeType {
    case work        // 工作时间25分钟
    case focus45     // 专注45分钟
    case focus60     // 专注60分钟
    case shortBreak  // 短休息5分钟
    case break10     // 休息10分钟
    case longBreak   // 长休息15分钟
    case break20     // 休息20分钟
    case custom      // 自定义时间
}
```
