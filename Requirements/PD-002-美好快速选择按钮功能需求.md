## 1. 功能概述

### 1.1 功能名称
美好快速选择按钮（Beautiful Quick Select Buttons）

### 1.2 功能目标
为番茄闹钟App增加一个美观、易用的快速时间选择功能，使用马卡龙色系设计风格，提供标准番茄钟时间的快速选择。

### 1.3 用户价值
- 提升用户体验：通过精美的UI设计增强视觉吸引力
- 提高操作效率：快速选择预设时间，减少手动输入
- 符合番茄工作法：提供标准的25/5/15分钟组合

## 2. 功能需求

### 2.1 核心功能 [FR-009]

#### 2.1.1 时间选项展示
- **选项内容**：
  - 工作时间：25分钟
  - 短休息：5分钟
  - 长休息：15分钟
- **展示格式**：每个选项显示时间数字、单位"分钟"和功能说明

#### 2.1.2 选择交互
- **选择模式**：单选模式，一次只能选择一个时间选项
- **触发条件**：仅在计时器未启动时可选
- **选择效果**：
  - 选中状态：按钮变为对应的马卡龙色渐变背景，文字变为白色
  - 未选中状态：白色背景，文字为对应马卡龙色
  - 禁用状态：灰色显示，不可点击

#### 2.1.3 应用逻辑
- **行为描述**：选择时间后仅设置时间，需要用户手动点击开始按钮
- **进度更新**：选择新时间时自动更新进度环显示
- **状态重置**：选择时重置秒数为0

#### 2.1.4 主题色联动 [FR-010] - 新增
- **功能描述**：快速选择按钮的主题色与倒计时显示区域和控制按钮实现颜色联动
- **联动范围**：
  - 倒计时圆环背景色和进度条色
  - 倒计时文字颜色（自动对比色调整）
  - 控制按钮（重置、开始/暂停、停止）背景色
- **实时切换**：计时过程中允许切换主题色，所有元素立即响应
- **颜色方案**：
  - 工作时间：温柔粉色系 (#F2D4DD)
  - 短休息：淡雅薄荷绿 (#D1E3DD)
  - 长休息：柔和淡紫色 (#E0D3E6)

### 2.2 界面设计需求

#### 2.2.1 布局设计 [NFR-008]
- **位置**：主界面底部，控制按钮下方
- **布局**：3列网格布局，整齐排列
- **间距**：按钮间水平间距8pt，垂直间距12pt
- **容器**：浅粉色半透明圆角卡片容器，带阴影效果

#### 2.2.2 按钮内容布局 [NFR-011] - 新增
- **布局结构**：每个按钮采用两行布局
  - **第一行**：时间数字 + 单位（如"25分钟"）
  - **第二行**：功能标题（如"工作时间"）
- **字体规格**：
  - 时间数字：24pt，粗体，圆角设计
  - 单位文字：12pt，中等字重
  - 功能标题：13pt，半粗体
- **按钮尺寸**：高度60pt，宽度自适应
- **行间距**：两行内容间距8pt，确保清晰分隔

#### 2.2.3 视觉风格 [NFR-009]
- **颜色方案**：
  - 工作时间：温柔粉色 (#F2D4DD)
  - 短休息：淡雅薄荷绿 (#D1E3DD)
  - 长休息：柔和淡紫色 (#E0D3E6)
- **容器背景**：浅粉色半透明背景 (#FAEBEC)
- **按钮样式**：
  - 尺寸：高度60pt，宽度自适应
  - 圆角：15pt
  - 阴影：选中时增强阴影效果，颜色跟随主题
  - 边框：未选中时显示对应主题色的细边框

#### 2.2.4 动画效果 [NFR-012]
- **按压动画**：点击时缩小到0.95倍
- **选中动画**：选中时放大到1.03倍
- **弹性效果**：使用Spring动画，响应时间0.3-0.4秒
- **状态切换**：选中状态变化时的平滑过渡
- **颜色过渡动画**：
  - 按钮选中状态：0.3秒Spring动画
  - 倒计时圆环颜色：0.5秒缓入缓出动画
  - 控制按钮颜色：0.3秒缓入缓出动画
  - 文字对比色调整：0.5秒缓入缓出动画

### 2.3 文案设计

#### 2.3.1 标题文案
- **主标题**："快速选择"
- **副标题**："点击选择时间"
- **字体**：SF Pro Rounded，字重Semibold

#### 2.3.2 按钮文案
- **工作按钮**："25" + "分钟" + "工作时间"
- **短休按钮**："5" + "分钟" + "短休息"
- **长休按钮**："15" + "分钟" + "长休息"

## 3. 技术实现

### 3.1 组件架构
- **主组件**：QuickTimePicker.swift
- **样式组件**：BeautifulQuickSelectButtonStyle（在ThemeStyles.swift中）
- **数据模型**：TimeOption结构体
- **主题联动**：selectedThemeType状态管理（在ContentView.swift中）

### 3.2 关键技术点
- **SwiftUI组件化开发**：使用独立的View组件
- **自定义ButtonStyle**：实现复杂的视觉效果和主题色切换
- **状态管理**：使用@State和@Binding管理选择状态和主题类型
- **动画实现**：Spring动画、ScaleEffect和颜色过渡动画
- **对比色算法**：根据背景色自动调整文字颜色以确保可读性

### 3.3 代码结构
```swift
// 组件文件
Demo5/Views/QuickTimePicker.swift
Demo5/Utils/ThemeStyles.swift（扩展）

// 样式定义
struct BeautifulQuickSelectButtonStyle: ButtonStyle

// 数据模型
struct TimeOption {
    let minutes: Int
    let title: String
    let type: TimeType
}
```
