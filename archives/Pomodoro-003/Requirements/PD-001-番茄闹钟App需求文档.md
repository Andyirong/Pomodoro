# 番茄闹钟App需求文档

**文档编号：PD-001**
**版本：1.0**
**创建日期：2025-12-17**
**最后更新：2025-12-17**

## 1. 项目概述

### 1.1 项目名称
番茄闹钟 App（Pomodoro Timer App）

### 1.2 项目目标
开发一款可爱风格的番茄闹钟App，帮助用户管理时间、提高专注度和工作效率。

### 1.3 目标用户
- 需要时间管理的学生和职场人士
- 喜欢可爱风格UI的用户
- 需要专注工具提升效率的用户

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 倒计时功能 [FR-001]
- **描述**：提供番茄工作法倒计时功能
- **要求**：
  - 支持自定义设置倒计时时间（分钟和秒数）
  - 快速选择预设时间（15、25、30、45、60、90分钟）
  - 上下滑动调整时间功能
  - 实时显示剩余时间
  - 环形进度条显示进度

#### 2.1.2 闹钟控制 [FR-002]
- **描述**：控制倒计时的开始、暂停、继续和停止
- **要求**：
  - 开始按钮：启动倒计时
  - 暂停/继续按钮：暂停和恢复倒计时
  - 重置按钮：重置当前倒计时
  - 长按停止功能：需长按3秒才能停止闹钟
  - 长按反馈：显示3秒进度环 + 振动反馈 + 音效提示

#### 2.1.3 历史记录 [FR-003]
- **描述**：保存和管理用户的倒计时使用记录
- **要求**：
  - 保留最近10条使用记录
  - 记录时长、备注、创建时间
  - 相同设置自动计数使用次数
  - 一键恢复历史设置
  - 查看完整历史记录

### 2.2 任务管理功能

#### 2.2.1 任务清单 [FR-004]
- **描述**：管理待办事项任务
- **要求**：
  - 添加、编辑、删除任务
  - 标记任务完成状态
  - 细化分类：工作项目、编程学习、阅读、运动、家务等
  - 设置优先级（高、中、低）
  - 设置截止日期
  - 任务统计和分析

### 2.3 健康管理功能

#### 2.3.1 休息提醒 [FR-005]
- **描述**：定时提醒用户休息
- **要求**：
  - 自定义休息间隔提醒
  - 眼睛保健操指导
  - 伸展运动建议
  - 提醒音效

#### 2.3.2 白噪音 [FR-006]
- **描述**：提供环境背景音帮助专注
- **要求**：
  - 内置环境音（雨声、森林、咖啡厅等）
  - 定时关闭功能
  - 音量控制

### 2.4 激励系统

#### 2.4.1 积分系统 [FR-007]
- **描述**：通过完成任务获得积分奖励
- **积分规则**：
  - 完成5分钟：+5积分
  - 完成15分钟：+10积分
  - 完成25分钟：+15积分
  - 完成45分钟：+20积分
  - 完成60分钟：+25积分
  - 完成90分钟：+30积分
  - 完成普通任务：+10积分
  - 完成高优先级任务：+20积分
  - 连续3天：+50积分
  - 连续7天：+100积分
  - 连续30天：+500积分

#### 2.4.2 成就系统 [FR-008]
- **描述**：通过使用App解锁成就
- **要求**：
  - 成就徽章收集
  - 连续完成天数统计
  - 累计完成番茄钟统计
  - 积分排行榜（本地）

## 3. 非功能需求

### 3.1 用户界面需求

#### 3.1.1 视觉风格 [NFR-001]
- **主题**：Q版可爱风格
- **色调**：粉色、紫色、马卡龙色系
- **设计元素**：
  - 圆润的界面元素
  - 柔和的渐变效果
  - Q版萌萌小萝莉助手角色

#### 3.1.2 助手角色设计 [NFR-002]
- **形象**：Q版萌萌小萝莉（大眼睛、圆脸、可爱表情）
- **功能**：
  - 根据不同状态变化表情
  - 眨眼、微笑等微动画
  - 状态包括：空闲、专注、暂停、完成

#### 3.1.3 动画效果 [NFR-003]
- **要求**：
  - Q弹的动画效果
  - 状态转换动画
  - 积分获得动画
  - 成就解锁动画

### 3.2 音效需求 [NFR-004]
- **音效类型**：
  - 萌系按钮点击音
  - 倒计时结束提醒音
  - 长按倒计时提示音
  - 任务完成奖励音
  - 成就解锁庆祝音

### 3.3 数据存储需求 [NFR-005]
- **存储方式**：SQLite本地数据库
- **数据表**：
  1. timer_history（番茄钟历史）
  2. tasks（任务清单）
  3. user_settings（用户设置和积分）
  4. achievements（成就系统）
  5. statistics（统计数据）
- **备份**：无需云同步，仅本地存储

### 3.4 性能需求 [NFR-006]
- App启动时间 < 3秒
- 倒计时精度误差 < 0.1秒
- 动画流畅度 ≥ 60fps
- 内存占用 < 100MB

### 3.5 兼容性需求 [NFR-007]
- iOS 15.0及以上版本
- iPhone设备适配
- 支持暗黑模式

## 4. 数据库设计

### 4.1 timer_history 表
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| minutes | INTEGER | 分钟数 |
| seconds | INTEGER | 秒数 |
| note | TEXT | 备注 |
| created_at | DATETIME | 创建时间 |
| usage_count | INTEGER | 使用次数 |

### 4.2 tasks 表
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| title | TEXT | 任务标题 |
| category | TEXT | 分类 |
| priority | INTEGER | 优先级（1-3） |
| deadline | DATETIME | 截止日期 |
| completed | BOOLEAN | 完成状态 |
| created_at | DATETIME | 创建时间 |

### 4.3 user_settings 表
| 字段名 | 类型 | 说明 |
|--------|------|------|
| key | TEXT | 设置键 |
| value | TEXT | 设置值 |
| total_points | INTEGER | 总积分 |
| current_streak | INTEGER | 当前连续天数 |
| longest_streak | INTEGER | 最长连续天数 |

### 4.4 achievements 表
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| name | TEXT | 成就名称 |
| description | TEXT | 成就描述 |
| unlocked_at | DATETIME | 解锁时间 |
| points_required | INTEGER | 解锁所需积分 |
| points_awarded | INTEGER | 奖励积分 |

### 4.5 statistics 表
| 字段名 | 类型 | 说明 |
|--------|------|------|
| date | DATE | 日期 |
| total_minutes | INTEGER | 总专注分钟数 |
| completed_tomatoes | INTEGER | 完成番茄钟数 |
| tasks_done | INTEGER | 完成任务数 |
