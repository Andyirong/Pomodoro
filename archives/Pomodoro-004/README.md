## 功能概述

本分支完成了番茄闹钟 App 的美好快速选择按钮功能，为用户提供了便捷的时间选择体验。

### 主要实现内容

#### 1. QuickTimePicker 组件
- 实现了全新的快速时间选择器组件
- 支持多种预设时间选项（15分钟、25分钟、30分钟、45分钟、60分钟、90分钟、120分钟）
- 采用两行布局设计：第一行显示时间数字，第二行显示时间标题
- 支持无限循环滚动

#### 2. BeautifulQuickSelectButtonStyle 样式
- 创建了专用的按钮样式
- 使用马卡龙色系配色方案
- 包含7种不同的颜色主题：
  - 薄荷绿（15分钟）
  - 天空蓝（25分钟）
  - 蜜桃粉（30分钟）
  - 阳光橙（45分钟）
  - 香草黄（60分钟）
  - 薰衣草紫（90分钟）
  - 珊瑚红（120分钟）

#### 3. 主题色联动功能
- 实现了按钮选中状态与主题色的动态绑定
- 倒计时圆环颜色会跟随选中按钮变化
- 控制按钮（开始/暂停/重置）颜色也会同步更新
- 使用 Color-Extensions.swift 中的颜色工具函数

#### 4. 动画效果
- 添加了平滑的颜色过渡动画
- 按钮选中/未选中状态切换有流畅的动画效果
- 使用 withAnimation 实现动画控制

#### 5. 布局优化
- 调整了整体布局，为快速时间选择器预留空间
- 将原控制按钮下移80个单位
- 优化了组件间的间距和对齐

### 技术实现细节

#### 主题系统
- 使用 @Environment(\.colorScheme) 自动适配深色/浅色模式
- 实现 themedColor 方法，根据系统主题自动调整颜色
- 所有颜色都支持深色模式适配

#### 组件架构
- QuickTimePicker 作为独立组件，可在多个地方复用
- 使用 @Binding 实现双向数据绑定
- 通过回调函数通知父组件时间变更
